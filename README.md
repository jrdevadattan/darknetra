# DARKNETRA

Evidence-first, multilingual narcotics-intelligence and criminal-network discovery platform for authorized investigators.

DARKNETRA is being developed for the Chandigarh Police National Hackathon 2026 — Problem Statement 3. The platform is designed to preserve source evidence, extract structured narcotics indicators, correlate cross-platform aliases, visualize investigation graphs, detect emerging trends, and generate evidence-linked investigation packs.

## Branch policy

- `main` — stable branch; no direct feature development.
- `testing-codex` — active integration and agentic development branch.

## Safety boundary

DARKNETRA is an intelligence-triage and evidence-correlation system for lawful, authorized use. It must not bypass encryption, authenticate to criminal services, contact sellers, facilitate drug purchases, defeat access controls, or treat automated inference as proof of guilt.

## Frontend foundation

The investigator dashboard will adapt selected MIT-licensed UI patterns/components from `arhamkhnz/next-shadcn-admin-dashboard`, with required attribution retained. Unrelated template modules will be removed rather than carried into the product.

## Status

Architecture/design specification phase. Implementation proceeds milestone-by-milestone on `testing-codex`.
