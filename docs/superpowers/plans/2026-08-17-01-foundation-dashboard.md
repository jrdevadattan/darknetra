# DARKNETRA Foundation and Investigator Dashboard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish the DARKNETRA monorepo, Dockerized local development baseline, and a cleaned investigator-facing Next.js dashboard derived from the approved `next-shadcn-admin-dashboard` source without carrying unrelated demo modules.

**Architecture:** `apps/web` is the investigator UI and is adapted from the pinned MIT-licensed dashboard snapshot. `apps/api` starts in this plan as a deliberately small FastAPI health/config service so Docker Compose and frontend-to-backend connectivity are real from day one; business APIs begin in Plan 02. Root tooling owns reproducible Node/Python versions, workspace commands, Compose, CI, and vendor-attribution checks.

**Tech Stack:** Node.js 24 LTS, pnpm 10.x, Next.js 16.3.x, React 19.2.x, TypeScript 5.9.x, Tailwind CSS 4.x, shadcn/Radix-style primitives, Recharts, Vitest, Testing Library, Playwright, Python 3.12.x, FastAPI 0.135.x, Pydantic 2.x, pytest, Docker Compose v2.

## Global Constraints

- Work only on branch `testing-codex`; `main` remains stable.
- Read `docs/superpowers/specs/2026-08-17-darknetra-dashboard-monorepo-design.md` and `docs/decisions/0001-frontend-template-baseline.md` before editing.
- Upstream dashboard source is pinned to `arhamkhnz/next-shadcn-admin-dashboard@0c668859c4fdeaa0279c951c178b965cce62a125`.
- Preserve `LICENSES/next-shadcn-admin-dashboard-MIT.txt` and any source-file copyright headers retained from upstream.
- Frontend version bounds: Node.js 24 LTS; Next.js `>=16.2.11,<17`; React `19.2.x`; TypeScript `>=5.8,<6`; pnpm `10.x`; Tailwind CSS `4.x`.
- Backend runtime: Python `3.12.x`; FastAPI `0.135.x`; Pydantic `2.x`.
- Use Recharts in the initial frontend because it is already in the pinned template. Do not introduce ECharts in this plan.
- PostgreSQL will be authoritative once persistence begins; Neo4j will be a rebuildable projection. This plan must not introduce business-state dual writes.
- Core startup and dashboard smoke tests must work without Tor, GPU access, a cloud LLM, or other external APIs.
- Imported/source material is untrusted. Do not add features that contact sellers, authenticate to criminal services, purchase controlled substances, defeat access controls, or bypass encryption.
- Use DARKNETRA epistemic labels such as `candidate`, `lead`, `pending analyst review`, `analyst-confirmed`, and `rejected`; never automatically label an account/person `criminal` or `guilty`.
- Do not keep template pages, packages, navigation entries, data fixtures, assets, or dependencies merely because they exist upstream.
- Every retained metric/card must link to a useful work queue or case view.
- No completion claim is valid without fresh test/lint/type/build/Compose verification output.

- [ ] **Step 4: Implement the repository-contract checker**

Create `scripts/check_repo_contract.py`:

```python
from __future__ import annotations

from pathlib import Path

UPSTREAM_REPO = "arhamkhnz/next-shadcn-admin-dashboard"
UPSTREAM_COMMIT = "0c668859c4fdeaa0279c951c178b965cce62a125"


def check_vendor_attribution(repo_root: Path) -> list[str]:
    errors: list[str] = []
    license_path = repo_root / "LICENSES" / "next-shadcn-admin-dashboard-MIT.txt"
    vendor_doc = repo_root / "docs" / "vendor" / "next-shadcn-admin-dashboard.md"

    if not license_path.is_file():
        errors.append("missing upstream MIT license")
    else:
        text = license_path.read_text(encoding="utf-8")
        if "Copyright (c) 2024 Mohammed Arham Khan" not in text:
            errors.append("upstream copyright notice missing")
        if "MIT License" not in text:
            errors.append("upstream MIT license text missing")

    if not vendor_doc.is_file():
        errors.append("missing dashboard vendor provenance document")
    else:
        text = vendor_doc.read_text(encoding="utf-8")
        if UPSTREAM_REPO not in text:
            errors.append("vendor document missing upstream repository")
        if UPSTREAM_COMMIT not in text:
            errors.append("vendor document missing pinned upstream commit")

    return errors
```
